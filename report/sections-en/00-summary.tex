\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This report presents an implementation in OpenFOAM-13, coupled with the
thermochemistry library \mpp{}, to reproduce the zero-dimensional test cases
used by Casseau \textit{et al.}~\cite{casseau2016} to validate the
two-temperature solver \hyfoam.
Park's two-temperature model, which distinguishes the
translational-rotational temperature $\Ttr$ from the vibro-electronic
temperature $\Tve$, is implemented by advancing the energy equations and
recovering the temperatures through \mpp{}, which also provides the
thermodynamic properties.

The verification uses two separate computational approaches that share the
same source-term functions. The first comprises stand-alone zero-dimensional
programs that integrate the heat-bath equations using \mpp{} alone and
reproduce all figures in the verification section of the reference study. The
second uses the CFD solver to integrate the same equations on a single cell,
with a thermophysical model providing the interface to the library. The two
approaches agree to within 0.3\% for the cases evaluated with both, except for
high-temperature nitrogen, where the difference reaches 1.2\%. This
comparison provides a check of the model's integration into the solver. The
physical model is assessed
against the \hyfoam{} curves extracted from the vector figures of the
reference study and the equilibrium temperatures obtained from energy
conservation.
